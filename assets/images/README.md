## How to Change or Add New Images

1. Download your chosen photo from Google Photos (or take a new camera photo).
2. For best web performance, resize or compress it (under 400 KB is ideal; JPEG or WebP format).
3. Replace the corresponding file name in `assets/images/` (e.g. replace `hero-team-scarlet.jpg` with your new photo of the same name).
4. Refresh your browser! The site will automatically display the new image with zero code edits required.
